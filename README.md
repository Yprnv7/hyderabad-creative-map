## 🧭 Overview & Core Architecture

Naksha is an interactive directory and hybrid mapping application covering the entire creative, design, hospitality, and nightlife ecosystem across Hyderabad.

- **Hybrid Mapping Architecture**: Powered by **CARTO Voyager & Positron** raster/vector tile engine with API key integration + interactive Leaflet canvas.
- **Google Maps & Places API**: City-wide live search and radar queries powered by Google Places API (New) with 1-click directions.
- **295+ Mapped & Verified Outposts**: Spanning Jubilee Hills, Banjara Hills, Madhapur, HITEC City, Gachibowli, Financial District, Begumpet, Secunderabad, Sainikpuri, and Old City.
- **Verified Contacts & Leadership**: Direct phone numbers, founder emails, Instagram profiles, LinkedIn dossiers, and one-click WhatsApp contact cards.
